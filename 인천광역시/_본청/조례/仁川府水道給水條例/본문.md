# 仁川府水道給水條例

##### 제1조

第三條 全文을 左記와 如히 改正함
水道給水條例의 種別을 區別하여 左의 二種으로함
第一種 家庭用
一號 全用給水 專用栓에 의하여 一戶 또는 一場所의 家事用에 供給하는 것
二號 私設公用給水 公用銓에 의하여 三戶以上의 家事用에 供給하는 것
第二種 非家庭用
一號 營業用給水 專用栓에 의하여 官公署, 兵營, 學校, 病院, 銀行, 會社 ,集會所, 市長, 鐵道停車場, 其他 集團家乃 營業用으로 供給하는 것
二號 浴場給水 湯室營業用에 供給하는 것
三號 工場給水 鐵道汽罐用, 工場, ,製造業, 釀造用으로 供給하는 것
四號 臨時給水工事業 其他 一時用에 供給하는 것
五號 公設用給水 領賣人은 指定하여 數號의 家事用에서 販賣하는 것
六號 船舶給水 取扱販賣人을 指定하여 船舶의 用에 供給하는 것

##### 제2조

第三十六條 全文을 左記와 如히 改正함
給水使用料는 左의 區分에 依하여 徵收함
第一種 家庭用給水使用料
一號 全用給水 戶別 또는 一場所一個月分一立方米室當『十円五十錢』七立方米室以上一立方米室增加에대하여四十八円을 加算함.
二號 私設公用給水 一戶二個月分一立方米室當 『十円五十錢』各號五入方二室以上一立方米室增加에대하여 『四十八円』을 加算함.
第二種 非家庭用給水使用料
一號 營業用給水 一號 또는 一場所一個月分一立方米室當『二四円』二十立方二室以上一立方米室增加에대하여 『四十八円』을 加算함.
二號 湯場給水 一個月分一立方米室當 『二四円』五十立方米室以上 一立方米室以上一立方米室增加에대하여 『四八円』을 加算함
三號 工場給水 二個月分五十立方米室까지 一立方米室當 『二四円』增加에 대하여 『四八円』을 加算함
四號 臨時給水 一立方米室에 對하여 『二四円』
五號 公設公用給水 一立方米室에 對하여 『二四円』
六號 船泊給水 一立方米室에 對하여 『二四円』
